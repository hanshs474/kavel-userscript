# Kavel userscript

Select any text on any web page and turn it into an AI image in place, with no API key and no account.

Install from [Greasy Fork](https://greasyfork.org/) (Tampermonkey, Violentmonkey or Greasemonkey), then
select a sentence and click **🎨 Image**. The menu command **Generate an image from a prompt…** works
without a selection.

It calls the free anonymous tier of [Kavel AI](https://www.kavel.ai/?utm_source=github&utm_medium=userscript).
Free output is 1K and watermarked, with a small daily allowance per machine.
